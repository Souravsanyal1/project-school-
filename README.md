# SchoolHub & Mega Store BD

A modern, responsive e-commerce web application with **Bangladeshi Taka (৳ BDT)** as base currency, full-control interactive **Admin Panel**, and floating **WhatsApp** customer support widget.

## 🌟 Key Features

- **Base Currency in BDT (৳)**: All product pricing, cart calculations, discounts, and invoices are in Bangladeshi Taka.
- **Full Control Admin Panel**:
  - Protected with Security PIN (Default: `admin123`).
  - Sales & Orders dashboard metrics.
  - Full CRUD for products, categories, coupons, and orders.
  - Customizable WhatsApp number, bKash / Nagad / Rocket merchant numbers, delivery fees, and announcement text.
  - JSON database backup & restore.
- **Storefront & Checkout**:
  - Live search, categories filter, and product quick-view modal.
  - Cart drawer & responsive checkout modal.
  - bKash, Nagad, Rocket, and Cash on Delivery (COD) payment methods with TrxID input.
  - Printable / downloadable invoice slips.
  - Real-time Order Tracking by Order ID or Phone number.
- **Floating WhatsApp Widget**:
  - Animated pulse button with quick chat popup and pre-filled message generator.

## 🚀 How to Run Locally

1. Clone or download the repository:
   ```bash
   git clone https://github.com/Souravsanyal1/project-school-.git
   cd project-school-
   ```
2. Open `index.html` directly in any web browser, or run a local server:
   ```bash
   python -m http.server 8080
   ```
3. Open `http://localhost:8080` in your browser.
